XIV MCP detects these plugins automatically. Its settings only mention the ones you have installed, and `/xivmcp` → **Info** → **Compatibility** shows what it found.

<Screenshot src="info-compatibility.png" alt="The Compatibility page of the Info tab, listing each installed plugin and how XIV MCP works with it" caption="/xivmcp → Info → Compatibility lists the plugins you have installed." width={700} />

## Plugins it pauses

| Plugin | What XIV MCP does |
|---|---|
| **AutoRetainer** | AutoRetainer starts processing ventures as soon as a bell opens. While XIV MCP uses the bell, it holds AutoRetainer back through its public interface and releases it a few seconds after the bell is closed. If AutoRetainer is busy or in multi mode, XIV MCP does not touch the bell. |
| **YesAlready** and **TextAdvance** | Paused while XIV MCP drives game windows, so they do not click for it. |
| **FCCH** | Handles FC chest transfers. Item moves wait while it works. |

## Plugins it uses

| Plugin | Used for |
|---|---|
| **vnavmesh** | Walking, for `navigate_to`, `buy_item` and `turn_in_collectables`. Without it, XIV MCP puts the flag on your map and you walk. |
| **Lifestream** | Teleports, houses, inns, the workshop and world visits. Without it, XIV MCP tells you where to teleport or what to enter. |
| **Artisan** | Crafting and crafting lists |
| **GatherBuddy Reborn** | Gathering and gathering lists |
| **AutoDuty** | Running and looping dungeons. The dungeon tools only exist while it is loaded. |
| **Item Vendor Location** | Finding vendors and appraisers, and `find_vendors`. Without it, you open the shop or go to the appraiser yourself, and XIV MCP does the rest. An **Install** button appears under *Market & purchases* when it is missing. |
| **Penny Pincher** | Its settings decide how much to undercut on the market board. |
| **WaymarkPresetPlugin** | Its waymark preset library |
| **FCCH** | FC chest deposits and withdrawals |

Which tool needs which plugin, and where to get each one, is listed on [Tools that need plugins](/docs/developer/plugin-api/tool-requirements).

None of them is required. XIV MCP's own tools work without them, asking you to do the part the plugin would have done. Only the integration tools (dungeons, crafting and gathering lists, vendor lookups, FC chest transfers) need their plugin, and they disappear from your assistant's tool list while it is not loaded.
