---
title: Removing XIV MCP from an app
description: Take XIV MCP out of an app again, or cut off every app at once.
---

Most apps are removed with a **Remove from …** button on their panel in `/xivmcp` → **Connect**. Claude Desktop and VS Code manage XIV MCP themselves, so you remove it there.

### ChatGPT

**Remove from ChatGPT** deletes the entry from `~/.codex/config.toml`, with a backup. Restart ChatGPT afterwards.

### Claude Desktop

In Claude Desktop, open **Settings** → **Extensions** → **Final Fantasy XIV (XIV MCP)** and click **Uninstall**, or switch it off there.

### LM Studio

**Remove from LM Studio** deletes the entry from Bionic's server list (or from the older app's `mcp.json`), with a backup.

### Claude Code

**Remove from Claude Code** runs `claude mcp remove` for the user-wide entry and for every project that has its own.

### VS Code

In VS Code, open the Extensions view, find **MCP Servers – Installed**, right-click `ffxiv` and choose **Uninstall**.

### Apps you set up by hand

Delete the `ffxiv` entry from the app's MCP settings, for example from `~/.cursor/mcp.json` for Cursor.

## Every app at once

Switch off the **Server** in the top right of the `/xivmcp` window, or generate a new access token with the arrows button next to the token in the **Connect** tab. Apps that still have the old token can no longer connect.
