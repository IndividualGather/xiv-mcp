## One click

In `/xivmcp` → **Connect**, choose **Claude Desktop** and click the button. XIV MCP writes a Claude Desktop extension (`xiv-mcp.mcpb`) and hands it to Claude Desktop, which shows its install screen. Click **Install** there.

- The Microsoft Store version of Claude Desktop does not open `.mcpb` files by double-click, so XIV MCP passes the file to its `claude-desktop.exe` command instead.
- If neither works, Claude Desktop opens next to a folder with the file selected. Drag the file into Claude Desktop.

<Screenshot src="connect-claude-desktop.png" alt="The Claude Desktop panel with the install button, Show file, the next steps and the connected status" caption="Once it is set up, the panel says so in green." width={640} />

## How the extension works

- Claude Desktop extensions run a local program instead of connecting over HTTP. The extension carries a small bridge script that runs on the Node.js that comes with Claude Desktop, and passes everything on to the game.
- While the game is closed, the extension stays connected without tools. The game's tools appear once you start the game.
- The extension contains your access token. If you generate a new token, install the extension again.
