## One click

In `/xivmcp` → **Connect**, choose **VS Code** and click the button. VS Code opens its own "install MCP server" prompt, which adds XIV MCP to your user profile. Confirm it there.

GitHub Copilot's agent mode then offers XIV MCP's tools in every workspace.

## Removing it

See [Removing XIV MCP from an app](/docs/user/connect/removing#vs-code).
