The dungeon tools work through **AutoDuty**, so they are only offered while AutoDuty is loaded. Where to get it is on [Plugins XIV MCP uses](/docs/user/plugins#where-to-get-them).

To let your assistant farm a dungeon:

1. Install AutoDuty and check that it can run the duty on its own.
2. In `/xivmcp` → **Modules**, under **Integrations maintained by XIV MCP**, set **AutoDuty** changes to *Allow* (or *Ask*).
3. Ask for it as a job, for example "Run the latest dungeon with NPC allies as a job until I have 500 more Poetics". *Background jobs* is allowed by default.

| Tool | What it does |
|---|---|
| `list_duties` | Duties AutoDuty has a path for, with level and item level, and the modes it can run them in: with NPC allies (*Duty Support*, *Trust*, *Squadron*), with a party (*Regular*) and more |
| `run_duty` | Runs a duty `loops` times, or `until` your inventory holds the items or currency you want |
| `get_duty_status` / `stop_duty` | What AutoDuty is doing (stage, duty, loop); stops it after the current fight |
| `leave_duty` | Leaves the current duty like the Duty Finder's Leave entry. If AutoDuty is running, it is stopped first, after the current fight. Works without AutoDuty too (module **Game & navigation**). |

## Farming a drop or a currency

One `run_duty` step loops the dungeon until the target is reached:

```json
{ "until": [{ "item": "Allagan Tomestone of Poetics", "gain": 500 }] }
```

Use `{ "item", "quantity" }` for "until I have this many" and `{ "item", "gain" }` for "until I have this many more". `gearset` switches to a combat job first; on a crafter or gatherer it is required.

<Callout type="warn">Your character fights for real, and can be defeated.</Callout>

## Stopping safely

A run takes about 20 minutes, so your assistant runs `run_duty` as a [job step](/docs/user/features/jobs). Pausing or cancelling the job (or its timeout) stops AutoDuty and leaves the duty, but **never mid-fight**: AutoDuty keeps fighting until you have been out of combat for a few seconds, and continues if a fight starts again before then.

## What XIV MCP changes in AutoDuty

For a run, AutoDuty's loop count, duty mode, unsynced setting and stop conditions are set temporarily (never saved), and its action after the run is set to do nothing. Everything is restored afterwards. Its "stop at item quantity" list is swapped in memory while the run lasts and put back after. This may need an update when AutoDuty changes.
