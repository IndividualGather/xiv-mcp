XIV MCP is a Dalamud plugin, so you need [XIVLauncher](https://goatcorp.github.io/) with Dalamud, the plugin framework it loads into the game.

## From the plugin repository

XIV MCP has its own plugin repository. You add it once, and Dalamud installs XIV MCP and keeps it up to date like any other plugin.

<Steps>
<Step>

In the game, type `/xlsettings` and open the **Experimental** tab.

</Step>
<Step>

Under **Custom Plugin Repositories**, paste this URL, tick **Enabled** and click **Save and Close**:

```
https://raw.githubusercontent.com/IndividualGather/xiv-mcp/master/repo.json
```

</Step>
<Step>

Type `/xlplugins`, search for **XIV MCP** and click **Install**.

</Step>
<Step>

Type `/xivmcp` to open its window, and [connect your AI app](/docs/user/connect).

</Step>
</Steps>

Each release is listed on [GitHub](https://github.com/IndividualGather/xiv-mcp/releases), with what changed.

## As a dev plugin

To try changes that aren't released yet, or to work on XIV MCP, build it yourself and load it from your PC. Turn off the installed XIV MCP first, so only one copy runs. You need the [.NET 10 SDK](https://dotnet.microsoft.com/download), [Git](https://git-scm.com/downloads), and XIVLauncher with Dalamud installed. Start the game once with Dalamud before you build, because the build uses Dalamud's files.

<Steps>
<Step>

Open PowerShell in the folder you want XIV MCP in, and build it:

```powershell
git clone https://github.com/IndividualGather/xiv-mcp.git
cd xiv-mcp
dotnet build XivMcp.slnx
```

</Step>
<Step>

In the game, open `/xlsettings` → **Experimental** → **Dev Plugin Locations**. Add the path to the built plugin, including the drive, such as `C:\Users\you\xiv-mcp\XivMcp\bin\Debug\XivMcp.dll`, and save.

</Step>
<Step>

Open `/xlplugins` → **Dev Tools** → **Installed Dev Plugins** and enable **XIV MCP**.

</Step>
<Step>

Type `/xivmcp` to open the settings window. Its **Connect** tab sets up your AI app.

</Step>
</Steps>

## The `/xivmcp` window

Everything about XIV MCP is in one window, with these tabs:

| Tab | What it is for |
|---|---|
| **Connect** | Setting up your AI apps, the server switch and the access token. See [Connecting your AI app](/docs/user/connect). |
| **Modules** | What XIV MCP's own tools may do. See [Modules and permissions](/docs/user/permissions/modules). |
| **Third-party plugins** | Tools other plugins offer. See [Third-party plugins](/docs/user/permissions/third-party). |
| **Jobs** | Background jobs and spending approvals. See [Background jobs](/docs/user/features/jobs). |
| **Overlay** | The small window that shows what is running right now. See [Overlay and screenshots](/docs/user/overlay). |
| **Info** | Recent activity, compatibility with your plugins, the full tools list and the caches. |

`/xivmcp selftest` runs a quick check of everything and prints the results in chat. See [Troubleshooting](/docs/user/troubleshooting).
