## Requirements

- The [.NET 10 SDK](https://dotnet.microsoft.com/download).
- XIVLauncher with Dalamud installed. The build references Dalamud from `%APPDATA%\XIVLauncher\addon\Hooks\dev`.

## Build

```sh
git clone https://github.com/IndividualGather/xiv-mcp.git
cd xiv-mcp
dotnet build XivMcp.slnx
```

The plugin is written to `XivMcp/bin/Debug/XivMcp.dll`, next to `XivMcp.Core.dll`.

## The projects

| Project | What it is |
|---|---|
| `XivMcp` | The Dalamud plugin: tools, game access, windows. Thin adapters around the core. |
| `XivMcp.Core` | Everything that does not need the game: tool registry and providers, capabilities, policies, the permission gate, side-effect analysis, the audit log, the integration catalog, job placeholders, the plugin API protocol, the self-test runner, map maths and client setup. No Dalamud reference. |
| `XivMcp.Tests` | xUnit v3 tests for `XivMcp.Core`. |
| `examples/HelloMcp` | The example plugin for the plugin API. |

## Load it in the game

<Steps>
<Step>

Open `/xlsettings` → **Experimental** → **Dev Plugin Locations**, add the full path to `XivMcp/bin/Debug/XivMcp.dll`, and save.

</Step>
<Step>

Open `/xlplugins` → **Dev Tools** → **Installed Dev Plugins** and enable **XIV MCP**.

</Step>
<Step>

Rebuild while the game runs: Dalamud reloads the dev plugin when the file changes. Background jobs come back paused after a reload.

</Step>
</Steps>
