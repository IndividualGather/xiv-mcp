---
title: Time limits
description: How long ChatGPT, Claude Code and Claude Desktop wait for one tool call, and how to raise it.
icon: Hourglass
---

AI apps stop waiting for a tool call after a while and cancel it. XIV MCP answers a call only when it is done, so this limit applies to the whole call. Job steps are not affected: they run inside XIV MCP, without a request held open.

| App | Limit for one call | Can you change it? |
|---|---|---|
| **ChatGPT** (Codex) | 60 seconds | Yes: `tool_timeout_sec` in XIV MCP's entry in `~/.codex/config.toml` |
| **Claude Code** | 60 seconds | Yes: a `timeout` in milliseconds in XIV MCP's server entry, or the `MCP_TOOL_TIMEOUT` environment variable |
| **Claude Desktop** | About 60 seconds | No. Users report that the limit is fixed and timeout settings are ignored. |

```toml title="~/.codex/config.toml"
[mcp_servers.ffxiv]
tool_timeout_sec = 600   # ten minutes
```

The values are from the apps' documentation and user reports as of October 2026, and may change. Claude Code's limit applies to the first byte of the answer; since XIV MCP sends nothing until the call is done, that is the whole call. A minute is plenty for reading the game and for most single actions. Anything that may take longer, such as a dungeon run, gathering or a whole crafting list, belongs in a job. See [Step by step or as a job](/docs/developer/plugin-api/jobs-or-steps).
